Robot Factory

Robot Factory is a browser-based factory management and tycoon game where you build different types of robots, manage your factory, earn money, purchase upgrades, complete customer orders, and track your progress.

Features
Factory dashboard with:
Money
Factory level
Electricity
Workers
Reputation
Production
Efficiency
Production queue
Daily profit
Factory value
Storage
Machine health
Research level
Factory rank
Multiple robots to build:
Toy Robot
Cleaning Robot
Delivery Robot
Security Robot
AI Assistant
Robot assembly workshop
Add different robot parts
Paint robots
Install features
Quality testing
Assembly progress tracking
Customer orders
Factory upgrades
Statistics
Achievements
Save, load, and reset game
Responsive design for smaller screens
Progress is stored using browser storage
Technologies Used
HTML5
CSS3
JavaScript (ES6)
Browser Local Storage

How to Play
Open the game in your browser.
Start with the money provided by the factory.
Choose a robot from the Robot Production section.
Open the assembly workshop.
Add the required parts.
Use the factory tools to prepare the robot.
Complete the robot.
Earn money from production.
Use your money to purchase factory upgrades.
Complete customer orders and improve your factory.
Track your progress through Statistics and Achievements.
Save your game whenever you want.
